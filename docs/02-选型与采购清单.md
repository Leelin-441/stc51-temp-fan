## 2. 关键结论：先看板子上有没有 ULN2003

### 2.1 有 ULN2003 → 电机驱动零成本（普中/清翔绝大多数情况）

普中 HC6800-ES / 清翔系列开发板上的 **ULN2003** 本来是给 28BYJ-48 步进电机用的，
但它内部就是 **7 路达林顿管阵列（含续流二极管）**，驱动一只 5V 直流小电机**绰绰有余**。

此时你的采购清单**极短**：

| 必需件 | 作用 |
|---|---|
| 4.7kΩ 电阻 ×1 | DS18B20 的 DQ(P3.7) 上拉到 +5V |
| 1N4007 二极管 ×1~2 | 电机两端续流保护（**必须**） |
| 470µF/16V 电解电容 ×1 | 吸收电机启动电流冲击，防止单片机复位 |
| 杜邦线一包 | 接线 |

**总价约 5~10 元**（不含运费）。

### 2.2 没有 ULN2003 → 两个替代方案

| 方案 | 元件 | 成本 | 难度 | 建议 |
|---|---|---|---|---|
| **买 ULN2003 模块** | ULN2003 驱动板（常和 28BYJ-48 打包卖） | 约 2~5 元 | ★ 最低：模块上有现成的 IN1~IN4 排针和 OUT 排针，杜邦线一插就行 | **推荐**，新手最省事 |
| **自搭 S8050 三极管** | S8050 ×1、1kΩ ×1、10kΩ ×1、1N4007 ×1 | 约 0.5~1 元 | ★★★ 中：要认三极管 E/B/C 三个脚，还要面包板 | 想省钱 + 想学电路，可选 |

> 三极管方案的完整电路图见 [`docs/images/fig4-motor-driver.png`](images/fig4-motor-driver.png) 的**方案 B**：
> `P1.0 →1kΩ→ 基极B`，`发射极E → GND`，`集电极C → 电机负极`，`电机正极 → +5V`，
> 基极到 GND 加 **10kΩ 下拉**（防止单片机复位期间引脚悬空导致电机乱转），
> 电机两端**反并联 1N4007**。

### 2.3 怎么确认你板上有 ULN2003（识别要点）

按下面顺序找，**任意一条命中即可**：

1. **找芯片**：板上找一颗 **16 脚 DIP 直插芯片**，丝印（白字）标着 **`ULN2003`** 或 **`ULN2003A`** / `ULN2003APG`。
   - 位置特征：**通常在步进电机接口旁边**，并且离一排 4 针或 5 针排针很近。
   - 芯片旁边一般还有 4 个 **贴片电阻**（1kΩ 左右，接在 P1 口低 4 位与芯片 IN 脚之间）和续流用的 **8 个二极管阵列**（部分封装内置）。
2. **找接口**：板上找标着 **"步进电机"** / **"STEP MOTOR"** / **"28BYJ-48"** 的 **4 针或 5 针排针**。
   - 5 针通常是 `VCC / IN1 / IN2 / IN3 / IN4`（或 `+5V / A / B / C / D`）。
   - 4 针通常是 `IN1~IN4`，VCC 单独从板上的 +5V 取。
   - **有这个接口 = 板上一定有 ULN2003**。
3. **找跳线帽**：部分普中板把 **P1 口低 4 位**到 ULN2003 IN 的连线做成了**跳线帽/短路块**。
   - 若跳线帽被拔掉，**P1.0 与 IN1 是断开的**，电机不会转——这是"代码对但电机不动"的头号原因。
   - 确认方法：万用表**通断档**量 `P1.0 排针 ↔ ULN2003 的第 1 脚(IN1)`；不通就把跳线帽插上，或直接用杜邦线短接。
4. **找不到芯片也不慌**：只要板上有"步进电机"接口，就按有 ULN2003 处理；实在都没有，走 2.2 的方案。

### 2.4 接线（有 ULN2003 时，与代码严格对应）

```
P1.0  ──────────►  IN1（ULN2003 输入）
电机正极 ────────►  +5V
电机负极 ────────►  OUT1（ULN2003 输出）
1N4007 反并联在电机两端（阴极接 +5V 侧）
ULN2003 COM ────►  +5V        ULN2003 GND ────►  与单片机共地
470µF 电容 ─────►  跨接在 电机电源 +5V 与 GND 之间（注意正负极）
```

**★ ULN2003 是低边（灌电流）反相驱动**，与 [`config.h`](../firmware/config.h) 的注释一致：

```c
/* ULN2003 是反相驱动器：IN 为高 → OUT 拉低（导通）→ 电机通电。 */
sbit MOTOR = P1 ^ 0;
#define MOTOR_ON   1     /* IN 高 → OUT 拉低 → 电机通电 */
```

所以软件上 `MOTOR = 1` 表示"通电"（正逻辑），**但硬件上负载必须接在 `+5V` 与 `OUT` 之间**。

### 关于"板载 18B20 座是否已带上拉"——怎么确认

板载 18B20 座**有些批次已经在 PCB 上焊了 4.7k 上拉电阻**，有些没有。两种确认方法：

- **方法 A（推荐，万用表）**：板子**断电**，万用表打**电阻档**，量 **`P3.7` 排针 ↔ `+5V` 排针**之间的电阻。
  - 读到 **约 4.7kΩ** → 板上已有上拉，**不用自己再接**；
  - 读到 **无穷大/开路** → **必须自己补一个 4.7k**；
  - 读到 **接近 0Ω** → 反了/短路，先查线。
- **方法 B（软件现象）**：不接上拉直接跑，串口帧 `SENSOR` 字段若稳定报 **`NOPRESENT`** 或 `NOINIT`，基本就是缺上拉（也可能是没插紧）。
- **保险做法**：**不管量出来是多少，都买一个 4.7k**——它只值几分钱，而缺上拉是新手最常踩的坑之一（见 [`docs/09-制作过程问题与解决办法.md`](09-制作过程问题与解决办法.md) 问题 2）。

| 档位 | 包含内容 | 估算总价 | 适合谁 |
|---|---|---|---|
| **A. 最小必要** | 板载 ULN2003 驱动（0 元）+ 4.7kΩ + 1N4007 + 470µF + 杜邦线 + 用已有充电宝供电 | **约 10~25**（其中杜邦线套装占大头） | **大多数人选这个**。只要板上有 ULN2003，这就是完整可跑的方案 |
| **B. 最小必要 + 串口模块/独立电源** | A 档 + CH340 USB-TTL 模块 + 5V 2A 适配器 | **约 30~55** | 板子没有板载 USB 下载口，或想用 [`tools/serial_test.ps1`](../tools/serial_test.ps1) 做自动化测试、不想占板载串口 |
| **C. 最小必要 + 两个升级件** | A 档 + 旋转编码器 + 0.96 寸 OLED（或电压表模块，更便宜） | **约 20~45** | 想要演示效果和讲解加分点，且愿意动手改 [`config.h`](../firmware/config.h) 的引脚 |

**如果板子上没有 ULN2003**（走 2.2 方案），在上面基础上加：

- 买 ULN2003 模块：**+约 3~6 元**（最省事）；
- 或自搭三极管：**+约 5~10 元**（S8050 + 1k + 10k + 1N4007，但要加面包板 **+约 5 元**）。

## 6. 十二个新手最容易买错 / 接错的坑

1. **坑**：把 5V 小电机**直接接在 51 的 IO 口**（比如 P1.0 与 GND 之间）上，以为"5V 对 5V 正好"。
   → **正确做法**：**绝对不行**。51 的 IO 口**单脚灌电流只有约 20mA**（拉电流更小），而 5V 小电机启动瞬间要 **几百 mA**、正常工作也在 **100mA 量级**。直连的两个后果：一是电机根本不转或转得极勉强，二是大电流经端口灌入会**烧 IO 口甚至整片单片机**。必须经 **ULN2003（或 S8050）** 做电流放大兼开关，单片机只出控制信号，功率电流走驱动器自己的回路。

2. **坑**：买了 ULN2003，却把电机接在 **`OUT` 与 `GND`** 之间，然后怎么改代码电机都不转。
   → **正确做法**：ULN2003 是**低边（灌电流）反相驱动器**，`OUT` 是"被拉到地的开关"，不是输出高电平的电源。负载**必须接在 `+5V` 与 `OUT` 之间**：`电机正极 → +5V`，`电机负极 → OUT1`。这就是 [`docs/09-制作过程问题与解决办法.md`](09-制作过程问题与解决办法.md) 里问题 3 的真实踩坑（当时还误以为芯片坏了）。**判断口诀：OUT 是"地"，不是"电源"。**

3. **坑**：觉得"ULN2003 内部已经有续流二极管了"，就把电机两端的 **1N4007 省掉**，或者电机离驱动器很远也不加。
   → **正确做法**：**必须加**。电机是**感性负载**，PWM 关断瞬间电流被强行切断，会产生**几十伏级的反向尖峰电动势**，足以击穿驱动管。ULN2003 内部的续流二极管只能保护**芯片自身**，而**长引线带来的寄生电感**仍会把尖峰耦合到电源和 IO 上。所以：**电机两端反并联一只 1N4007**（银色色环端/阴极接 `+5V` 侧），并且**就近安装、引线尽量短**。

4. **坑**：为了省事让电机**从开发板上的 +5V 取电**，结果电机一启动，数码管闪一下、单片机就复位，串口 `ms` 字段归零。
   → **正确做法**：**电机必须独立供电**。① 电机电源用**单独一路 5V**（充电宝 / 5V≥1A 适配器）；② **两路 GND 必须接在一起（共地）**，否则 ULN2003 的控制信号没有参考电平，驱动会**完全失效**；③ 在电机电源的 `+5V` 与 `GND` 之间**并一只 470µF 电解电容**（尽量靠近电机），吸收启动电流冲击、稳住电压。这是文档 09 问题 4 的根因。

5. **坑**：DS18B20 的 DQ（P3.7）**没接 4.7k 上拉**，串口 `SENSOR` 字段一直报 `NOPRESENT` / `NOINIT`，或读数全是 0。
   → **正确做法**：DS18B20 的 DQ 是**开漏/准双向**结构，**自己不能输出高电平**，必须靠外部上拉电阻把总线拉高——这是 1-Wire 总线"空闲态为高"的基础。**接一只 4.7kΩ，一端到 DQ(P3.7)，另一端到 +5V**。两个附加要点：**① 上拉必须接到 +5V，不要图方便接板上的 3.3V 排针**（5V 器件的输入高门限 `V_IH = 0.7 × VDD = 3.5V`，3.3V 刚好够不着，会出现"有时能用有时不能用"的临界故障）；**② 上拉电压要与 DS18B20 的 VDD 同源**。

6. **坑**：买到**假的 / 翻新的 DS18B20**，读数常年就是 `85.0℃` 或 `0.0℃`，怎么捂都不变，于是开始怀疑自己的代码。
   → **正确做法**：**先分清"假货"和"时序错"**。`85.0℃` 是 DS18B20 的 **Power-on Reset 默认值**——它不代表"很热"，而代表"**这次转换根本没完成**"。所以：① 确认代码里发完 `0x44` 转换命令后**等了 ≥750ms**（本项目用 `DS_CONV_MS = 800`）；② 如果时序没问题、上拉也接了，读数**依旧恒为 85.0 或 0.0 且换位置也不变**，那才怀疑器件——**这时换一颗备用 DS18B20 立刻能分辨**，这就是建议多买一颗备用的原因；③ 认准"原装 Dallas"，几毛钱的散装货假货率高。详见文档 09 问题 1。

7. **坑**：觉得板载蜂鸣器"声音太小/太单调"，**又买了一个蜂鸣器**，结果新买的接上去不响（或只"嗒"一声）。
   → **正确做法**：蜂鸣器分**有源**和**无源**两种，**买错就白花钱**。① **有源蜂鸣器**内部自带振荡电路，**给高低电平就响**，板上那颗就是这种（P1.5 低电平响，板上还有三极管驱动），代码里只做定时开关（`BEEP_ON/OFF`），**不需要 PWM**；② **无源蜂鸣器**没有振荡电路，**必须用 PWM/方波驱动**才能发声，直接给直流只会"嗒"一声。本项目**用板载蜂鸣器即可，不用买**；若非要外接，一定买**有源**的。

8. **坑**：直接在 P1.0 上写代码驱动电机，**没注意板载 ULN2003 的输入脚默认接 P1 口的低 4 位**，而这几脚又和**矩阵键盘 / 流水灯**共用，跳线帽位置不对。
   → **正确做法**：普中/清翔板上 **P1 口低 4 位**经常是**多路复用**的（ULN2003 输入、矩阵键盘行/列、流水灯），靠**跳线帽/短路块**选择去哪。① **先看跳线帽**：确认 `P1.0 → ULN2003 IN1` 那一路是连通的；② **用量通断档验证**：万用表量 `P1.0 排针 ↔ ULN2003 第 1 脚(IN1)`，不通就插上跳线帽或直接用杜邦线短接；③ 若键盘/流水灯占用了同一脚，**把它们的跳线帽拔掉**；④ 本项目为了避开冲突，已经把 **LED 放在 P2.0/P2.1**、**按键只放在 P3.2/P3.3**、**LCD 控制线放在 P2.5~P2.7**。

9. **坑**：明明按 9600 配置了串口助手，收到的却全是乱码，或者板子用 **12MHz 晶振**但代码里 `FOSC_HZ` 还是 11.0592MHz 的值。
   → **正确做法**：**先确认晶振频率**（看板上金属壳晶振上的丝印）。① 本项目目标板是 **11.0592MHz**，此时 9600bps **误差为 0**，所以 [`config.h`](../firmware/config.h) 定的是 `BAUD_RATE 9600`；② 如果你的板子是 **12MHz**，**只改 [`config.h`](../firmware/config.h) 的 `FOSC_HZ` 这一行**（改成 `12000000UL`）——定时器重装值、PWM 周期、串口波特率**全部会自动重算**，不需要手改其它文件；③ 此时 [`firmware/uart.h`](../firmware/uart.h) 会**自动把波特率降级到 4800**（因为 12MHz 下跑 9600 误差高达 **+8.5%**，串口一定乱码），**所以串口助手和 [`tools/serial_test.ps1`](../tools/serial_test.ps1) 的 `-Baud` 参数也要跟着改成 4800**。忘记改这一处，就会看到"板子在发但全是乱码"。

10. **坑**：为了"接线方便"，用 **40cm 甚至更长的杜邦线**接 DS18B20，结果读数偶发跳变、`BADCRC` 时有时无。
    → **正确做法**：**杜邦线长度控制在 ≤20cm**。长线的**线间电容**会加大上拉电阻的 RC 上升时间，而 1-Wire 读时隙的采样点在主机拉低后**约 11µs**，边沿还没建立起来就采样了，于是产生**间歇性 CRC 错误**——这类"时好时坏"的故障比彻底不通更难查。同样地，**电机的引线也要尽量短**（减少寄生电感耦合尖峰，见坑 3）。

11. **坑**：470µF **电解电容正负极接反**，上电瞬间"啪"一声，电容鼓包甚至炸开。
    → **正确做法**：电解电容**有极性，反接会炸**。① **认脚**：**长脚是正极(+)**，壳体上**印白色竖条/带"-"号的一侧是负极(-)**；② **认板**：有些板/面包板会印 `+` 号；③ 本项目里它跨接在电机电源的 `+5V` 与 `GND` 之间，**正极接 +5V、负极接 GND**；④ **上电前先通电前检查一遍极性**，并且**第一次上电时手别离开电源开关**；⑤ 想彻底避免极性风险，可以改用**无极性陶瓷电容**（但要达到 470µF 容量体积和成本都不划算，不推荐）。

12. **坑**：用一个 **5V 500mA 的旧充电头**给电机供电，空转正常，一装上扇叶或用手轻按就掉电/复位。
    → **正确做法**：**电源必须留余量**。5V 小电机**空载电流约 100~200mA**，但**启动瞬间和堵转时可达约 1A**（文档 05 的 L3-11 项就是专门测堵转的）。所以：① 供电选 **5V / ≥1A**，**2A 更稳**；② **不要用电脑的 USB 口**直接给电机供电（USB 口通常限流 500mA，且会拖垮整个 USB 控制器）；③ **务必加 470µF 电容**缓冲启动冲击；④ 想量化验证就用第 4 节的 **0.28 寸电压表模块**盯着电压——**全速运行时电压不低于约 4.8V** 才算供电合格。

## 7. 下单前速查清单

### 7.1 下单前（先确认，再花钱）

- [ ] 我已翻过开发板，**确认板上有没有 ULN2003**（16 脚直插芯片 或 "步进电机" 4/5 针接口）
- [ ] 若没有 ULN2003，我已决定走 **买模块（约 3~6 元）** 还是 **自搭 S8050**
- [ ] 我已用万用表量过 **`P3.7 ↔ +5V` 之间是否已有约 4.7kΩ 上拉**（不通就要买 4.7k）
- [ ] 我已确认开发板**晶振是 11.0592MHz 还是 12MHz**（决定串口助手用 9600 还是 4800）
- [ ] 我已确认板子是**板载 CH340（一根 USB 线搞定）** 还是**需要另买 USB-TTL 模块**
- [ ] 我已确认手上**有没有充电宝 / 5V≥1A 电源**，能不能给电机独立供电
- [ ] 我已确认板载 ULN2003 的 **P1.0 → IN1 跳线帽**是否需要插上（万用表通断档量过）
- [ ] 我把上面的散件**合并到一两家店下单**，避免运费超过元件本身

### 7.2 收货后（上电前必查）

- [ ] **1N4007 方向**：银色色环（阴极）朝 **+5V** 侧 —— 反接会短路
- [ ] **470µF 极性**：长脚(+) 接 **+5V**，白条侧(-) 接 **GND** —— 反接会炸
- [ ] **电机接法**：正极 → **+5V**，负极 → **ULN2003 OUT1**（**不是** OUT 与 GND 之间！）
- [ ] **ULN2003 的 COM 接 +5V、GND 与单片机共地**
- [ ] **电机电源与单片机电源共地**（外接电源 GND ↔ 板子 GND 必须连一根线）
- [ ] **4.7k 上拉**：一端 P3.7 / DQ，另一端 **+5V**（不是 3.3V）
- [ ] **P1.0 → ULN2003 IN1** 通路（跳线帽已插 / 杜邦线已接，量过通断）
- [ ] **杜邦线全部 ≤20cm**，且没有半插、没有松脱
- [ ] **第一次上电手不离开电源开关**，先看有没有冒烟/发烫/异味

### 7.3 上电后（30 秒功能自检）

- [ ] 数码管正常显示（不闪、不缺段、不是全灭）
- [ ] 串口帧 `$S,...` 的 `SENSOR` 字段显示 **`OK`**（**不是** `NOPRESENT`/`BADCRC`/`NOINIT`）
- [ ] 温度读数**能随手捂/松开而变化**（若恒为 `850` 即 85.0℃，回到坑 5、坑 6 排查）
- [ ] 电机在 `LEVEL` 升档时能转起来，且**转速随占空比明显变化**（34% → 66% → 100%）
- [ ] 电机全速运转时，**板子不复位**（串口 `ms` 字段持续递增、不归零）
- [ ] 串口发 `SIM T=42.5` 能注入温度并触发报警，发 `SIM OFF` 能回到真实传感器
- [ ] 连续运行 **10 分钟**，ULN2003 与电机**不发烫到无法触摸**

### 7.4 排错顺序（按这个顺序查，别乱拆）

`供电（电压/共地）→ 驱动接线（OUT 还是 +5V）→ 控制信号通路（P1.0→IN1）→ 上拉与线长 → 器件本身（换备用件对比）`

> **先怀疑流程和接线，最后才怀疑器件。** 这是文档 09 用两次踩坑换来的经验：
> `85.0℃` 不是温度而是"我还没准备好"的错误码，DS18B20 读到 0 多半是上拉问题。
